# 游戏策划联动：从示例到 UE 项目

此目录可以复制到独立临时目录体验，或把对应文件逐个合入已有项目；不要批量覆盖现有项目。`ue-bindings.example.json` 仅是示例，不会自动导入不存在的资产。

## 五分钟演示

先在本 skill 的仓库根目录运行以下 PowerShell 命令，复制到新的临时目录。模板初始数值为伤害 100、冷却 2 秒；init 只用于尚未建立基线的新副本。

```powershell
$skillRoot = (Get-Location).Path
$projectRoot = Join-Path ([System.IO.Path]::GetTempPath()) ('game-design-sync-demo-' + [guid]::NewGuid().ToString('N'))
Copy-Item -LiteralPath (Join-Path $skillRoot 'assets/starter') -Destination $projectRoot -Recurse
python "$skillRoot/scripts/design_sync.py" init --manifest "$projectRoot/design-sync.json"
python "$skillRoot/scripts/impact_scan.py" acknowledge --manifest "$projectRoot/design-links.json"
$projectRoot
```

打开 Design/skills.md，将受管 JSON 块中 damage 的 100 改成 120。执行：

```powershell
python "$skillRoot/scripts/design_sync.py" plan --manifest "$projectRoot/design-sync.json"
python "$skillRoot/scripts/design_sync.py" apply --manifest "$projectRoot/design-sync.json"
python "$skillRoot/scripts/design_sync.py" check --manifest "$projectRoot/design-sync.json"
```

Tables/skills.csv 和 GameData/skills.json 将同步为 120。再直接在游戏 JSON 中把 Cooldown 改成 3，运行同一组命令，Markdown 和 CSV 将反向更新。

如果先在 Markdown 改伤害为 130，同时在 CSV 改为 140，plan 会报告基线和两个新值并退出 2，apply 不覆盖任何一侧。解决方式是先按实际设计意图把冲突字段显式改成一致，再 apply。验证命令失败时，恢复的是 apply 前状态，保留你原先手改的内容。

完成所有关联规则/代码复核后再 acknowledge；只执行文件 apply 后语义检查仍报变化是正常的，它提醒检查受管块外的规则与实现。

## Excel

CSV 可用 Excel 打开，但 ID 列应以文本导入。需要直接维护 XLSX 时，在选定 Python 环境安装 openpyxl，将 table view 改为如下结构，并先从原有表数据建立普通数据页：

```json
{"id":"table","path":"Tables/skills.xlsx","format":"xlsx","sheet":"Skills","data_only_sheet":true}
```

第一行是 id、damage、cooldown、enabled 等字段名。只有普通无公式数据页适用。改清单后按 skill 的迁移流程复核并 rebaseline，不可用 init 覆盖旧基线。

## 正式接入

先让 Codex：

> 使用 $game-design-sync，接入这个 Unreal 项目的技能系统，沿用现有 Markdown 和 Excel/CSV，建立到实际 DataTable、C++/蓝图与验收场景的映射。先检查漂移，再完成同步和验证。

之后可直接说：

- 使用 $game-design-sync，把火球伤害改为 120，同步策划、配表和 UE。
- 使用 $game-design-sync，我在 UE 表里调了冷却，把策划和 Excel/CSV 同步回来。
- 使用 $game-design-sync，把技能改成长按蓄力、松开发射，同步规则、参数、实现与测试。

UE 路径、Python 插件、真实行结构、C++/蓝图定位和验证命令需在实际项目接入时填入。详见 skill 的 references/unreal.md。本示例和文件测试均不代表 UE 编译或 PIE 已通过。
